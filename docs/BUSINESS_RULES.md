# FT 统计与业务规则

核对日期：2026-10-15；以当前 `ft-core.js`、`app.js` 和 README 为依据。此文记录现状及保护边界，不授权修改计算。

状态标签：**[代码]** 已实现并在本次定点核对；**[测试]** 本次 15 项合成核心回归覆盖的部分；**[文档]** README/历史状态说明；**[对话未验证]** 历史业务描述而非本次实机证据；**[待确认]** 不足以确定的政策。

## 1. 四种数量口径必须分开
| 口径 | 分子 | 分母 | 含义与来源 |
| --- | --- | --- | --- |
| 测试事件良率 | 当前范围 Pass 事件数 | 当前范围全部明细事件数 | [代码] `analyze`；总览八卡、Pareto、趋势等的基础 |
| 包含空封批次良率 | 初测 Pass + 各轮 RT Pass | 初测原始投入 | [代码/测试] `analyzeSubLots`，数量链试算 |
| 不包含空封批次良率 | 同上 | 初测投入 − 当前末轮空封 | [代码/测试] 非全轮累减，见第 4 节 |
| 工厂/正式生产参考 | 唯一匹配工厂报告产出或正式区间主品产出 | 工厂投入或正式区间投入 | [代码/文档] `analyzeProductionFlow`，不是总览替代口径 |

- [代码/测试] RT Pass 已计入批次分子，不加入批次分母；测试事件统计则逐行计数 FT/RT/Loop 等选中明细。
- [代码] 总览不按跨文件产品唯一 ID 去重，也不让最后一次 RT 覆盖所有初测结果；导入同内容文件去重是另一层处理。
- [代码] 测试事件零记录时 `yield` 为 0；批次分母无效或链路不成立时保留 null/数据不足，不用 0% 冒充结论。
- [代码/文档] 简易/专业模式只改变展示深度，不改变计算群体或分母；当前批次面板隐藏不表示取消批次算法/报告。

## 2. 原始结果与 Fail 归因
- [代码] ETS 优先使用 Soft Bin 定义的 P/F 标记，缺定义时按数值 SBIN=0 判断 Pass。
- [代码] PowerTECH、DataLog 按 SBin 字符串 `1` 判断 Pass；Loop XLSX 复用相应解析并保留循环角色。
- [代码] ATX 优先显式 Pass/P 或 Fail/F；未明确 Fail 时回退 SBin=1，缺 SBin 再参考 HBin=1。
- [代码/文档] 不直接按实测是否超限改写测试机 Pass/Fail；结果和参数超限可以不一致。
- [代码] 每条 Fail 记录保留解析所得单一 `failReason`，Pareto 按此累计；未知测试项保留 SBIN 原因，不能静默丢弃。
- [代码/文档] ETS/PowerTECH 使用相应 Bin/测试定义映射；DataLog 优先取 SBin 对应 HiFBin/LoFBin 的首个超限项，无匹配时回退首个其他超限项。
- [代码] ATX 优先取 Test Number 对应超限项，再回退首个超限项；无超限而编号唯一时可保留该测试项及未知方向。
- [代码] 方向：实测 <LSL 为低、>USL 为高，等于边界算规格内；缺数值/无法归因保留 unknown。
- [代码] Fail 占比 = 该原因 Fail / 全部 Fail；批次事件占比或良率损失 = 该原因 Fail / 全部测试事件，以百分点展示。
- [代码/文档] 以上损失不是承诺可恢复良率；一个参数的全部实测超限数可大于该参数归因 Fail 数，不得将两者合并。

## 3. FT / RT 数量链与遗失差额
- [代码/测试] 子批按产品 + 客户批号 + 子批号分组；取 Sub Lot Number / MES LotID 等元数据，缺子批号独立保留并阻止确定链路。
- [代码/测试] 总批按产品 + 客户批号汇总；任一缺失不跨子批拼成一个总批。
- [代码/文档] 文件名独立 FT/FT1/FT2 表示初测阶段；RT/RT1/RT2 表示复测轮次。阶段编号与时间用途不同，不按导入顺序判断末轮。
- [代码/测试] 同一子批必须有且仅有一个可识别初测阶段；不同 FT 阶段不得直接当作同轮分片合并。
- [代码/测试] 同阶段分片仅在格式、程序、测试定义兼容，且 Site/Serial 完整、不重叠时可合并；编号重启或重叠、程序冲突不能自动拼接。
- [代码/测试] 轮内重复 Site/Serial、空轮、时间倒置、多个初测、RT 投入超过上轮 Fail 等阻止确定链路。
- [代码/测试] 初测之后允许 RT 或 RT1 作为首轮，之后要求轮次连续；缺轮不能把跨轮差值判为遗失，不能输出确定链路良率。
- [代码/文档] QA、Loop、Summary 不计生产恢复；BIN/阶段不明文件进入待确认，不自动计入初测或 RT 恢复。
- [代码，待确认差异] pending 文件本身不必然使已识别链的 `yield` 为 null；它会保留说明，父批 `pending` 可为 true。不能把该数值描述成已确认完整批次；是否应全面阻止展示需用户决定。
- [代码/文档] 假设：每轮 Pass 退出后续复测，上一轮全部 Fail 应进入下一轮；尚无跨文件稳定产品 ID 证明这一假设。
- [代码/测试] 复测恢复 R = 各 RT 轮 Pass 之和；累计通过 P = 初测 Pass + R；初测投入 N = 初测合并后的 CSV 记录数。
- [代码/测试] 对相邻已确认轮次：差额 d = 上轮 Fail − 下轮投入。d>0 是待确认遗失差额，保留在 N 中；d<0 是异常，不跨子批用另一正差额抵销。
- [代码/测试] 没有下一轮时末轮 Fail 仍是不良，不是遗失；有效链满足 N = P + 末轮 Fail + 各轮正差额之和。
- [代码/测试] 包含空封良率 = P/N；总批用各有效子批数量求和后相除，不平均百分比。存在无有效良率子批时总批不出完整确定值，可保留可核对小计。
- [对话未验证] 用户明确空封也会被测试机当 OS Fail 投入复测；规则不能预先把空封从 RT 输入剔掉。
- [待确认] 正差额是否为真实落料遗失、初测中哪些是调机数据、最后导入轮次是否批次完结，均不能由现有文件数量单独判定。

## 4. 空封识别与扣除
- [代码/测试] 识别与 `isPass` 分开，保留原结果；不以 HBin5、OS Fail、单项极端值或全项精确相等代替特征判定。
- [代码] 产品名称匹配仅 `LX3418` / `LX3418C`，格式 ETS / PowerTECH，单位须为 V，排除 QA / Loop。
- [代码/测试] 至少两个**不同前置 OS 项**满足各自目标电压 ±0.05V；有限数值才参与，POST OS 不参与，也不要求执行。
| 格式 | 前置项 | 特征目标（V） |
| --- | --- | --- |
| ETS | VDD_OS / V1_OS / V2_OS / V3_OS | −1.982 / −2.065 / −2.058 / −2.023 |
| PowerTECH | OS_VDD / OS_V1 / OS_V2 / OS_V3 | 均为 −2.9 |
- [代码/文档] Fail 明细、搜索和导出保留空封标记；不自动修改 Bin 或测试机判定。
- [代码/测试] 有 RT 取当前已导入的最高编号 RT 空封数 E，无 RT 取初测；同轮兼容分片合并计数。不按导入顺序、不累加 FT/所有 RT 的空封。
- [代码/测试] 不含空封良率 = P/(N−E)；遗失差额仍在分母，不能同时作为空封再扣。
- [代码/测试] N−E≤0 或 P>N−E 时，该子批不输出排空封良率；不裁剪成 100%。
- [代码] 总批按 ΣP/(ΣN−ΣE)；需完整有效链。全空封且零通过子批在总批有非零有效投入时可并入，但子批自身不输出 0/0。
- [代码/文档] 当前最高 RT 只是截止轮次，不证明全部 Fail 已完成复测。
- [文档/测试边界] 参数据曾提供样本校准；本次只重新跑合成测试，原样本未重跑。
- [待确认] 其他产品/程序/单位的特征与容差、可否扩大识别范围必须先提供依据；“两个及以上偏大”不得解释为全产品通用阈值。
- [历史来源冲突] 早期对话的旧记忆登记“四个 OS 全部约 −2.9V”和根目录旧状态文档“只扣初测空封”均已过时，被后续两项命中/末轮扣除替代，不恢复旧候选规则。

## 5. 分布和规格模拟
- [代码/文档] 分布使用当前选中参数全部有限实测值（含 Pass/Fail）；普通生产稳定性用 Pass，这是两个不同群体。
- [代码] 各点保留来源文件自身规格；跨文件上下限或单位不同记为多规格，禁止一组统一 LSL/USL 模拟。
- [代码/文档] 默认规格聚焦会截取显示窗口；顺序图边界标视窗外数量，直方图仅绘当前窗口，并显示显示数/总数。它不是删掉异常样本。
- [代码] 模拟初始预计 Pass = 实际 Pass；仅归因于当前项、原本超限而新规格内的记录增加 Pass；原 Pass 从原规格内变新超限的记录减少 Pass。
- [代码] 其他原因 Fail、缺少有效实测的记录不因该项放宽而恢复；原始测试结果与其他 Fail 归因不被改写。
- [代码] 模拟事件良率 = 预计 Pass / 原事件总数；变化是与实际事件良率之差，界面以百分点显示。参数合格率 = 新规格内有效值 / 本参数有效值数。
- [代码/文档] 原规格模拟结果保持实际事件良率，不直接替代复测链批次良率或工厂最终产出。
- [代码] LSL/USL 步进 0.1；输入与拖线联动，恢复原规格保留；LSL>USL 提示错误，不出有效模拟结果。

## 6. 稳定性与 Ppk
- [代码/测试] 普通生产仅取 Pass 实测；Loop 取全部循环（包括 Fail）；混合输入分别选样后汇总有效同名值。
- [代码] 用有限有效值计算 n、均值和样本标准差 s = sqrt(Σ(x−均值)²/(n−1))，不是总体标准差或组内短期波动。
- [代码] 有双边时 Ppk = min((USL−均值)/(3s), (均值−LSL)/(3s))；单边时仅使用存在的边界。
- [代码] n≤1 标准差/Ppk 为 null；s=0 且 n>1 时均值在规格内为 +Infinity，否则 −Infinity；保留当前边界处理，不擅自换为零。
- [代码/文档] n<30 标为样本不足，即便能算出 Ppk；n≥30：Ppk≥1.33 稳定，≥1 关注，其余风险；Ppk 缺失仍不足。
- [代码] 双边有效规格宽度下规格利用率 = 6s/(USL−LSL)，中心偏移按距规格中点/半规格宽度计算。
- [代码，待确认] 同名参数合并时规格/单位差异标记 `specVariant`，现状仍可能沿用首个目录规格算 Ppk；跨单位转换、产品分组和是否停止显示能力指标尚未确定。
- [文档] Pass 条件统计与 Loop 重复测量统计都不能直接当作整批生产过程能力结论，需结合量测系统、抽样和工程规范。

## 7. 去重、角色及工厂参考
- [代码] CSV 解码后统一 BOM/换行，再以 SHA-256 + 解析阶段 + 角色 + Summary/detail 类型识别重复；不同阶段不互相去重。XLSX 沿用现有规则。
- [文档/代码] Summary 独立分析，不与明细累加、不自动关联明细逐颗数据；仅报告内部自洽检查，停用不存在的逐颗参数视图。
- [文档/代码] 工厂 XLSX 仅在产品/客户批号/子批等唯一匹配时采用；同批多行或多文件歧义不随意选择。
- [文档] 正式区间可按唯一工厂投入从初测尾部反推，支持人工起点覆盖并保留审计；不因此改变批次链的原始投入 N。
- [代码/文档] 工厂推算恢复取 max(0, 工厂产出−正式初测主品通过)，推算最终不良取 max(0, 工厂投入−工厂产出)；只是数量推算，不是逐颗复测覆盖。
- [代码/文档] HBin1 主品、HBin8 单列、HBin3 电性、HBin5 O/S、其余其他处置是当前映射；O/S 不等于空封。
- [待确认] HBin 映射需产品流程卡确认；工厂真实投入、调机剔除、重复测试、混批、工厂最终良率政策仍需人工业务依据。
- [文档] 测试时间优先明确逐条/文件字段，缺失不按起止时间推测；UPH=3600×1000/(测试时间ms+150ms)，日产出=UPH×20×85%，汇总时间按有效记录加权。
